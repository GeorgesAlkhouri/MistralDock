# Security policy

## Supported versions

Security fixes are applied to the latest `0.1.x` release line.

## Reporting a vulnerability

Please do not include API keys, Paperless tokens, document contents, or other sensitive data in a public issue.

Use the repository's private GitHub Security Advisory reporting flow when it is available. If private reporting is not enabled, open a minimal public issue requesting a private contact channel and include no vulnerability details.

Reports should include the affected version, a concise reproduction, impact, and any suggested mitigation. We will acknowledge the report and work on a fix before public disclosure where practical.
